# 卫星通信完整流程（通俗版 + 专业拆解）

卫星通信本质：**地面站 → 射频信号 → 卫星转发器 → 另一地面站**，卫星相当于空中中继基站。

> 
> 分两大场景：**固定卫星通信（VSAT）**、**移动卫星终端（你的卫星终端，含手持 / 车载）**

## 一、基础组成

1. **用户终端（UE）**：你的卫星终端（带天线、调制解调器、射频单元）
2. **信关站 / 网关（Gateway）**：地面主站，对接互联网 / 专网
3. **通信卫星**：在轨，含接收天线、转发器、发射天线
4. **链路**：上行（地面→卫星）、下行（卫星→地面）

## 二、完整通信流程（一次数据 / 通话建立）

### 1. 捕获与跟踪（天线对准卫星）

终端上电，天线开始**搜星**：

- 获取星历，计算卫星方位角、俯仰角
- 天线转动 / 相控阵波束对准卫星
- 锁定载波，完成同步（频率、时间）

> 
> 卫星终端测试工作重点是这一步：搜星、载波锁定、信噪比监测

### 2. 信令接入（注册、建链）

终端向卫星发送**接入请求**，信号经卫星转发到地面信关站：

1. 信关站校验终端身份（鉴权、授权）
2. 分配信道资源（时隙 / 频点 / 波束）
3. 返回接入成功信令 → 链路建立

> 
> 类似手机注册基站。卫星是透明转发，**信令本身卫星不解码，只放大 + 变频转发**（透明转发器，最常见）

### 3. 业务传输（上行 + 下行）

✅ **上行链路（终端 → 卫星）**
用户数据（语音 / IP 包）→ 基带调制编码 → 射频放大 → 天线发射 → 上行载波到卫星。
卫星收到信号：**低噪放大 → 变频（改变频段）→ 功率放大**，不解析内容。

✅ **下行链路（卫星 → 接收端）**
卫星把信号转发下发 → 远端终端天线接收 → 射频解调 → 基带解码 → 还原 IP / 语音数据。

> 
> 双工：同时收发（频分双工 FDD 居多，上下行不同频段）

### 4. 通信维持

持续发送导频、同步信号；
信道质量变差时，信关站调整功率、编码速率、波束。

### 5. 通信释放

业务结束，终端 / 网关发拆链信令 → 释放卫星信道资源。

## 三、频段划分（常用）

- L/S 波段：低速率，手持卫星终端（铱星、北斗短报文）
- Ku 波段：VSAT，互联网卫星
- Ka 波段：高通量卫星 HTS，大带宽

## 四、两种典型卫星转发模式

1. **透明转发（弯管转发，绝大多数商用通信卫星）**
卫星只做放大、变频，**不解调、不解码**；所有编解码、路由全部在地面网关。优点简单可靠，终端测试就是测这个链路。
2. **星上处理（OBP）**
卫星上直接解调、交换数据包，再重新调制下发，星上交换机，低轨星座常用。

## 五、关键损耗（卫星终端测试重点）

- 自由空间损耗（距离越远损耗越大，GEO 最明显）
- 雨衰（Ku/Ka 雨天衰减严重）
- 天线增益、极化损耗

## 六、举个例子：手里的卫星终端上网流程

终端开机 → 天线搜星对准卫星 → 注册入网 → IP 包调制射频发射 → 卫星弯管转发 → 地面信关站 → 接入互联网；下行反过来。
