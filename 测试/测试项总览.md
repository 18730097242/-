# 卫星通信终端测试项

## 一、射频指标测试

1. **发射指标**

- 发射频率误差
- 输出功率（最大发射功率、功率控制范围）
- 发射 EVM（误差矢量幅度）
- 发射频谱模板、杂散发射、谐波
- 发射邻道泄漏比 ACLR

2. **接收指标**

- 接收灵敏度
- 最大输入电平（过载 / 1dB 压缩点）
- 接收噪声系数 NF
- 选择性（邻道选择性、阻塞、杂散响应抑制）
- 接收 EVM

## 二、信号与链路测试

- 接收信号强度 RSSI
- 载噪比 C/N
- 链路裕量测试
- 多普勒频偏捕获与跟踪
- 信号解调性能（不同 C/N 下 BER 误码率、PER 包误码率）
- 链路建立、保持、断开性能

## 三、业务功能测试

- 注册 / 入网、鉴权
- 短消息业务收发
- IP 数据业务：Ping、TCP/UDP 吞吐量、时延、抖动
- 语音业务（如有）
- 多业务并发
- 休眠 / 唤醒、省电模式

## 四、协议与信令测试

- 信令流程：attach、位置更新、连接建立、释放
- 信令超时重传、异常信令容错
- 切换（星间 / 波束切换，如有）
- 随机接入性能

## 五、模拟器环境测试（信道模拟器、卫星模拟器）

- 静态信道下终端通信性能
- 多径衰落信道
- 多普勒动态变化场景
- 衰减动态变化（链路裕量变化）
- 干扰叠加场景

## 六、接口测试

- 网口：速率、连通性
- 串口：日志输出、AT 指令交互
- 电源接口：电压范围、功耗（待机 / 发射 / 接收功耗）
- 天线接口驻波 SWR

## 七、环境可靠性测试

- 高低温工作
- 振动、冲击
- 电源波动、浪涌
- 静电 ESD

## 八、稳定性与异常测试

- 长时间连续业务稳定性（拷机）
- 掉电、热重启、冷重启
- 断链后重连恢复
- 过功率、强干扰下终端保护

## 九、天线相关测试

- 天线驻波比 VSWR
- 方向图、增益
- 收发隔离度

卫星终端测试专有名词解释

| 专有名词 | 释义 |
| --- | --- |
| 频率误差 | 终端实际发射载波频率与标称频率之间的差值，反映本振频率准确度。 |
| 输出功率 | 终端射频端口发射信号功率，包含最大发射功率、功率控制区间。 |
| EVM 误差矢量幅度 | 衡量调制信号质量指标，表示实际调制符号与理想符号之间矢量误差的比值，单位 %。EVM 越大，信号畸变越严重。 |
| 频谱模板 | 规范射频信号频谱的掩膜曲线，发射频谱不能超出模板限制，防止干扰邻信道。 |
| 杂散发射 | 载波以外不需要的多余射频信号，包含谐波、寄生分量，需要抑制在规定电平以下。 |
| ACLR 邻道泄漏比 | 发射信号泄漏到相邻信道的功率和本信道功率比值，表征发射机对邻道的干扰程度。 |
| 接收灵敏度 | 终端在满足规定误码 / 包误码指标下，天线口能正确解调的最小输入信号功率。 |
| 噪声系数 NF | 接收机引入噪声的恶化程度，表征接收机内部噪声大小，数值越低接收性能越好。 |
| 邻道选择性 | 接收机在相邻信道存在干扰信号时，正常接收有用信号的能力。 |
| 阻塞 | 存在强的偏离载波干扰信号时，接收机不会过载、不会失效的能力。 |
| 杂散响应抑制 | 抑制接收机在特定寄生频点上对干扰信号错误响应的能力。 |
| 1dB 压缩点 | 射频器件输出功率不再随输入线性增长，增益下降 1dB 对应的功率点，表征接收机最大线性输入能力。 |
| RSSI 接收信号强度指示 | 终端测量到的接收信号总功率，包含有用信号 + 噪声 + 干扰。 |
| C/N 载噪比 | 载波功率与噪声功率比值，单位 dB，代表信号纯净程度。 |
| 链路裕量 | 实际接收载噪比减去解调所需最低载噪比，代表链路预留余量，余量越大链路越稳定。 |
| 多普勒频偏 | 终端与卫星相对运动带来载波频率偏移，终端需要捕获并跟踪该频偏。 |
| BER 误码率 | 传输错误比特占全部传输比特的比例。 |
| PER 包误码率 | 接收错误数据包占全部数据包的比例。 |
| 鉴权 | 网络侧验证终端身份合法性，防止非法终端接入。 |
| Attach 附着 | 终端向卫星网络发起注册入网流程，建立网络上下文。 |
| 位置更新 | 终端更新自身位置 / 波束信息，通知网络当前所在服务小区 / 波束。 |
| 随机接入 | 终端初始发起上行连接、同步时使用的接入流程。 |
| 波束切换 | 终端从一个卫星波束切换到另一个波束，保持业务不中断。 |
| 多径衰落 | 信号经不同反射路径到达接收端，各路信号叠加造成信号幅度起伏。 |
| AT 指令 | 串口控制终端的命令集，用于查询状态、配置参数、收发业务。 |
| VSWR 电压驻波比 | 天线端口入射波与反射波比值，反映天线与射频端口匹配程度，VSWR 越小匹配越好。 |
| ESD 静电放电 | 静电冲击测试，验证终端抗静电损坏能力。 |
| 时延 | 数据包从发送端到接收端花费的时间。 |
| 抖动 | 连续数据包之间传输时延的波动范围。 |
| 吞吐量 | 单位时间成功传输的数据量，常用 Mbps。 |
| 拷机 | 长时间连续运行业务，验证终端长时间工作稳定性。 |
