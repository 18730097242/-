# 快速对比表

表格

| 仪器 | 核心用途 | 典型输出指标 |
| --- | --- | --- |
| 信号源 | 产生射频激励信号 | 载波、调制信号，作为信号激励源 |
| 频谱仪 | 频域功率观测 | 载波功率、底噪、杂散、C/N |
| 矢量信号分析仪 | 数字调制质量分析 | EVM、频偏、定时误差、星座图 |
| 信道模拟器 | 通用无线信道仿真 | 路径损耗、多普勒、多径衰落 |
| 卫星模拟器 | 卫星转发链路闭环仿真 | 卫星变频、星地时延、动态多普勒、雨衰 |
