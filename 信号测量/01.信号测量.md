# 信号测量：内容 + 测量方法（蜂窝 + 卫星终端）

## 一、信号测量主要内容

分为**射频功率类、信噪比类、解调性能类、同步与时序类、链路损耗类**

### 1. 射频功率测量

表格

| 指标 | 测量内容 |
| --- | --- |
| RSSI | 接收带宽内全部信号总功率（信号 + 噪声 + 干扰） |
| RSRP（4G/5G） | 参考信号单点接收功率，表征小区信号强度 |
| RSRQ（4G/5G） | 参考信号质量，RSRP 与 RSSI 比值，反映干扰 |
| EIRP（卫星） | 终端发射有效全向辐射功率，发射机 + 天线综合输出能力 |

### 2. 信噪比类

表格

| 指标 | 测量内容 |
| --- | --- |
| SINR | 信干噪比，有用信号 /(干扰 + 噪声)，决定解调上限 |
| C/N₀（卫星核心） | 载波功率 / 噪声谱密度，衡量载波与底噪水平，判断载波能否锁定 |
| Eb/N₀ | 每比特能量与噪声谱密度，衡量数字解调品质 |

### 3. 解调性能测量

表格

| 指标 | 测量内容 |
| --- | --- |
| BER | 误码率：传输比特出错比例 |
| BLER | 块误码率：传输块解调失败比例，业务测试关键指标 |

### 4. 同步与时序测量

表格

| 指标 | 测量内容 |
| --- | --- |
| 载波频偏 | 接收载波和本地本振的频率差值 |
| 定时误差 | 信号接收时序偏差；蜂窝用 TA 补偿 |
| 捕获时间 | 终端从开始搜星 / 搜小区到同步锁定耗时（卫星重点指标） |

### 5. 链路损耗与接收品质（卫星）

表格

| 指标 | 测量内容 |
| --- | --- |
| G/T | 接收品质因数，天线增益 / 系统噪声温度，代表接收灵敏度 |
| 路径损耗 | 空间传播损耗；卫星额外包含雨衰、极化损耗 |

---

## 二、测量方法（两大类：**仪表测试法 + 终端内部测量上报法**）

### 方法 1：专用仪表测试（实验室，最精准，产线 / 型式测试）

> 
> 仪表：信号源、频谱仪、矢量信号分析仪、信道模拟器、卫星模拟器

1. **射频端口测试（有线，不带天线）**
   - 终端射频口通过同轴电缆接仪表
   - 信号源下发调制信号，模拟基站 / 卫星下行信号
   - 仪表直接读取功率、频偏、C/N0、EIRP、BER
   - 优点：无空间干扰，可复现；缺点：无法评估天线空中性能
2. **暗室空口 OTA 测试（辐射测试，带天线）**
   - 在微波暗室内，仪表通过发射天线辐射信号给被测终端
   - 测整机 OTA 接收灵敏度、EIRP、天线增益、G/T
   - 优点：贴近真实空中环境；缺点：设备昂贵，测试环境要求高

### 方法 2：终端内置测量（终端自测量，外场实测）

终端基带芯片内部解调链路完成测量，通过日志 / 信令上报

- 蜂窝：小区搜索时测量 RSRP/RSRQ/SINR，测量报告上报 gNB
- 卫星：终端基带解调模块计算 C/N0、频偏，上报网关或输出日志

> 
> 优点：外场方便，不需要外接仪器；缺点：精度低于专业仪表，是相对测量值

### 方法 3：外场实测（空中真实链路）

1. 蜂窝：在真实基站覆盖区域，终端采集空口信号，记录 RSRP、SINR、BLER，可结合扫频仪定点 / 移动测试
2. 卫星：终端天线对准卫星，搜星锁定后，读取终端日志 C/N0；同时记录俯仰角、方位角，可做雨衰测试（雨天对比 C/N0 变化）

## 三、蜂窝与卫星测量差异总结

表格

| 项目 | 地面蜂窝终端信号测量 | 卫星终端信号测量 |
| --- | --- | --- |
| 核心指标 | RSRP、RSRQ、SINR、BLER | C/N0、EIRP、G/T、Eb/N0 |
| 同步测量 | PSS/SSS 下行同步，TA 定时补偿 | 载波捕获、频偏跟踪、天线方位俯仰跟踪 |
| 主要测试设备 | 综测仪、扫频仪 | 卫星信道模拟器、频谱仪、微波暗室 |
| 主要干扰 | 多径干扰、邻区干扰 | 自由空间损耗、雨衰、极化失配损耗 |
| 测量关注点 | 小区覆盖、切换性能 | 载波锁定余量、天线跟踪、链路裕量 |




### 专有名词释义
表格

| 缩写 | 英文全称 | 中文释义 | 详细说明 |
| --- | --- | --- | --- |
| RSSI | Received Signal Strength Indicator | 接收信号强度指示 | 接收带宽内**全部功率总和**，包含有用信号、噪声、干扰，仅表征总能量，不能单独反映信号质量。 |
| RSRP | Reference Signal Received Power | 参考信号接收功率 | 4G/5G 蜂窝专用，只测量参考信号的功率，代表小区信号强弱，单位 dBm，小区选择核心指标。 |
| RSRQ | Reference Signal Received Quality | 参考信号接收质量 | RSRP 与 RSSI 的比值，用来评估信号纯净度，体现干扰水平。 |
| SINR | Signal to Interference plus Noise Ratio | 信干噪比 | 有用信号功率 ÷（干扰功率 + 噪声功率）；决定解调能力，SINR 越高，可支持更高传输速率。 |
| C/N₀ | Carrier to Noise Density | 载噪比 | 载波功率与噪声功率谱密度之比；卫星通信最核心指标，判断载波能否锁定，单位 dBHz。 |
| Eb/N₀ | Energy per Bit to Noise Power Spectral Density | 每比特能量噪声谱密度比 | 单个信息比特能量和噪声谱密度比值，衡量数字解调性能，和调制编码方式相关。 |
| EIRP | Effective Isotropic Radiated Power | 有效全向辐射功率 | 发射机输出功率 + 天线增益 − 馈线损耗；代表天线向空间辐射信号的能力。 |
| G/T | Gain/Temperature | 接收品质因数 | 接收天线增益除以系统噪声温度；表征接收整机接收弱信号的能力，G/T 越大接收灵敏度越好。 |
| Path Loss | Path Loss | 路径损耗 | 电磁波在空间传播产生的功率衰减；GEO 卫星存在巨大自由空间损耗，蜂窝多为近地传播损耗。 |
| BER | Bit Error Rate | 误码率 | 传输比特中错误比特占总比特的比例，衡量数字信号解调好坏。 |
| BLER | Block Error Rate | 块误码率 | 传输块解调失败的比例；业务测试核心指标，上层业务丢包直接和 BLER 相关。 |
| 载波频偏 | Frequency Offset | 载波频偏 | 接收信号载波频率，和接收机本地载波频率的差值；频偏过大，解调失败。 |
| 定时误差 | Timing Error | 定时误差 | 接收信号实际到达时刻和本地预期时刻的偏差；蜂窝通过 TA 补偿上行定时。 |
| 捕获时间 | Acquisition Time | 捕获时间 | 终端从开始搜索信号，到载波 / 帧同步锁定完成消耗的时长；卫星搜星重点指标。 |
| Link Margin | Link Margin | 链路裕量 | 实际接收 C/N₀减去接收机解调最小 C/N₀门限；链路的安全余量，用来抵御雨衰、对准偏差等信号恶化。 |
| 信号源 | Signal Source | 信号源 | 仪表设备，产生射频调制信号，模拟基站 / 卫星下发信号，用于实验室测试。 |
| 频谱仪 | Spectrum Analyzer | 频谱分析仪 | 观测信号频域特性，测量功率、带宽、杂散、噪声底。 |
| 矢量信号分析仪 | Vector Signal Analyzer | 矢量信号分析仪 | 可解析调制信号，测量 EVM、频偏、C/N0 等数字调制指标。 |
| 信道模拟器 | Channel Simulator | 信道模拟器 | 模拟空间传播效应：路径损耗、多普勒、多径、雨衰等，复现空中信道环境。 |
| 卫星模拟器 | Satellite Simulator | 卫星模拟器 | 专用信道仪表，模拟卫星转发链路、多普勒、衰减，对卫星终端做闭环测试。 |
| 微波暗室 | Anechoic Chamber | 微波暗室 | 内壁吸波材料，消除电磁波反射；用于 OTA 空口辐射测试，测天线、整机射频性能。 |
| OTA | Over-the-Air | 空口测试 | 不接射频同轴线缆，通过空间电磁波测试整机天线辐射 / 接收性能。 |
| 射频端口测试 | RF Port Test | 射频端口有线测试 | 终端射频口同轴电缆直连仪表，跳过天线，单独评估射频模块性能。 |
| 扫频仪 | Spectrum Sweep Receiver | 扫频仪 | 在频段内扫描，采集空中信号功率，外场路测使用。 |
| 衰减器 | Attenuator | 衰减器 | 射频器件，可控降低信号功率；用来模拟链路损耗，测试接收机门限与链路裕量。 |
